FastAPI backend for [CVerity](https://github.com/mdharishsuhaib/CVerity), an AI-powered resume analyzer and job matching system.

- Health check: `/health`
- Interactive docs: `/docs`

Configure it with **Settings > Variables and secrets** on this Space (see the main repository README, section 8).
